# Research Notes for Cisco Implementation

Codex must use official primary sources for command syntax and platform/version behavior.

Preferred source classes:

1. Cisco IOS-XE Configuration Guides
2. Cisco IOS-XE Command References
3. Cisco Programmability Configuration Guides
4. Cisco YANG model documentation
5. Cisco Feature Navigator
6. IETF RFCs and OpenConfig models where applicable

For every implemented capability, record:

- capability key;
- exact Cisco document title;
- document/release version;
- platform/model assumptions;
- command or YANG path;
- verification source;
- known platform differences;
- date checked.

Do not rely on Wikipedia, community posts or random blogs as command authority.
Do not mark syntax verified without a recorded primary source.
