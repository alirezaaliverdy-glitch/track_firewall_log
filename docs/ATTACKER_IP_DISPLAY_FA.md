# نمایش سادهٔ IP در بخش مهاجمان

سه کارت بزرگ «پوشش تشخیص»، «Geo / ASN» و «حجم داده» از صفحهٔ مهاجمان حذف شده‌اند. این حذف فقط مربوط به نمایش است؛ موتور تشخیص، رویدادهای ذخیره‌شده و سیاست نگهداری تغییر نکرده‌اند.

با انتخاب یک IP، بخش «کشور و شبکهٔ IP» کشور تقریبی، پرچم، کد دوحرفی کشور، شمارهٔ ASN و مالک شبکه را از پایگاه محلی DB-IP نشان می‌دهد. کشور بر اساس **IP مبدأ رویداد** تعیین می‌شود، نه مقصد ترافیک و نه مکان قطعی شخص مهاجم. اگر IP خصوصی باشد، کشور اینترنتی نمایش داده نمی‌شود؛ اگر پایگاه آماده نباشد، همین وضعیت صریحاً نوشته می‌شود. مدیر سامانه می‌تواند با دکمهٔ کوچک پایین صفحه پایگاه را به‌روزرسانی کند. برای هر IP درخواست بیرونی فرستاده نمی‌شود. پرچم به‌صورت نویسهٔ استاندارد Unicode نمایش داده می‌شود و ظاهر آن به فونت/سیستم‌عامل مرورگر بستگی دارد.

در «آخرین شواهد» ابتدا فقط سه لاگ کوتاه دیده می‌شود. با بازکردن هر ردیف، متن کامل همان شاهد دیده می‌شود؛ «نمایش همه» بقیهٔ شواهد موجود را باز می‌کند. کوتاه‌شدن نمایش به معنی حذف لاگ نیست.

کشور و ASN برای شناخت منشأ شبکه کمک می‌کنند، اما به‌تنهایی دلیل مسدودکردن IP نیستند. برای اقدام، یافته‌های امنیتی، زمان، دارایی‌های هدف و شواهد وندور را هم بررسی کنید.
