# Cisco Capability Matrix

Milestone 18.2A status:

- Implemented read-only: platform/version, inventory, CPU/memory, interface status, IP interface brief, VLAN list, trunk list, EtherChannel summary, STP summary, routing table and ACL list.
- Planned mutations: VLAN create/update/delete, access/trunk ports, EtherChannel workflows, routing changes, ACL lifecycle, service changes and configuration lifecycle.
- Unsupported for IOS-XE connector: NX-OS, IOS-XR, ASA, FTD and unknown platforms.

The UI route `/assets/vendors/cisco` displays the real capability status. No capability is shown as complete Cisco support.
