# Open-Source Capability Translation

The goal is not to clone projects. The goal is to translate their strongest product concepts into tested internal capabilities.

## NetBox
Use source-of-truth, site/location, IPAM/VLAN, preview/apply/conflict and drift patterns.

## Wazuh
Use agents, alerts, normalized events, rule metadata and finding creation.

## OpenSearch Security Analytics
Use bounded search, detector state, correlations and rule synchronization.

## Sigma
Use portable structured rules, validation, import/export and testing.

## MITRE ATT&CK
Use evidence-based technique mapping, coverage and blind spots.

## OCSF
Use normalized event concepts and mapping-quality reporting.

## DefectDojo
Use finding lifecycle, duplicate/merge, accepted risk, false positive, SLA and remediation verification.

## TheHive
Use case/task/observable/timeline concepts only. Do not copy archived/commercial code.

## Grafana
Use time ranges, panels, annotations, thresholds and drill-down.

## Uptime Kuma
Use heartbeat, uptime, latency, incidents, maintenance windows and history.

## Required proof

For each concept document:

- module;
- API;
- route;
- workflow;
- tests;
- real/mock state;
- license review;
- user-visible proof.
